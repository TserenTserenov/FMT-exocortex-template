# Genre Template: Post

> **Human-readable skeleton** for a post author.
> The register (how to write) comes from the base style; this file defines the structure (what the document consists of).

## Structure

1. **Opening (1–2 sentences).** The main idea first. Why the reader should care.
2. **Body.** One argument per paragraph. Examples from the physical world or engineering.
3. **Turn / insight.** What changes in the reader's picture of the world.
4. **Call to action or question.** One concrete implication or an open question.

## Guidance (tips for the author)

- Document longer than two screens → use collapsible sections (`<details>`), no horizontal dividers.
- The first paragraph carries the essence; examples and references go at the end under a collapsible section.
- Em dash only in "X — is Y" constructions.
- Adapt the tone to the audience; do not hard-code it into the template.
