# Genre Template: Guide

> **Human-readable skeleton** for the author of a universal guide.
> Personal adaptation for a specific reader is a separate layer on top; this template defines
> the structure that remains universal for any reader.

## Structure

1. **Why (motivation).** What problem the method solves — no filler.
2. **What (definition).** The method in one paragraph.
3. **How (steps).** Numbered steps, each verifiable.
4. **Example.** One concrete run-through of the method.
5. **Common mistakes.** What to avoid (negative definition).
6. **Mastery check.** How to confirm the method is working.

## Guidance (notes for the author)

- A universal guide = a method for everyone, with no ties to a specific reader. Personal adaptation is a separate Artifact on top of this skeleton.
- Academic register: precise definitions, but no academicism for its own sake.
- Each step is an action, not a description.
