## Подписанные паки (только чтение)

> Этот файл создал скилл `/pack-subscribe`, он же пополняет список ниже. Файл ваш: обновление
> шаблона его не трогает. Агент читает его в начале каждой рабочей сессии (протокол открытия,
> точка расширения `protocol-open after`).

Чужие паки по подписке: читать и искать — да, править — **никогда** (только `git pull`).
Нашли ошибку или устаревшее → сообщить владельцу (замечание в его репозитории), не исправлять молча.
Адаптация → копия в СВОЙ пак с пометкой источника (пак, файл, коммит или дата).

**Автообновление.** Сейчас, в начале сессии, молча выполнить команду ниже (копии только для
чтения, обновление их не портит, разрешения спрашивать не надо). Если что-то обновилось —
одной строкой сказать, какие паки; если нет — не упоминать вовсе.

```bash
W="${IWE_WORKSPACE:-$HOME/IWE}"
EXT="$W/extensions/protocol-open.after.pack-subscriptions.md"
sed -n 's/^- `\(PACK-[A-Za-z0-9._-]*\)`.*/\1/p' "$EXT" | while read -r p; do
  [ -d "$W/${p}/.git" ] || { echo "${p}: копии нет — подключить заново: /pack-subscribe ${p}"; continue; }
  before=$(git -C "$W/${p}" rev-parse HEAD)
  git -C "$W/${p}" pull --ff-only --quiet || { echo "${p}: не обновился (нет сети или локальные правки)"; continue; }
  after=$(git -C "$W/${p}" rev-parse HEAD)
  [ "$before" = "$after" ] || echo "${p}: обновлён, новых коммитов: $(git -C "$W/${p}" rev-list --count "${before}..${after}")"
done
```

**Область поиска по умолчанию (настройка — меняется прямо здесь).**
default_scope: all-connected
> `all-connected` — поиск идёт по своим знаниям и всем подписанным пакам сразу.
> `own-only` — поиск только по своим знаниям; подписанные паки — по прямой просьбе.
> Смена: скажите агенту «сделай по умолчанию own-only» (или наоборот) — он поправит строку
> `default_scope` выше; можно отредактировать её и самому. Разовое отклонение на один ответ —
> фразой «ищи только в моих» / «посмотри и в подписанных паках», без смены настройки.
> В ответе агент помечает, из какого пака взято знание.
