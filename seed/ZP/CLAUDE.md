## Rules

1. **The principles list is open.** The current 6 (ZP.1-ZP.6) form the core, but new principles may be added when trans-disciplinary meta-constraints are discovered. Criterion: the principle must apply across ALL domains (physics, biology, society, IT, cognition). Candidates: metacognition/recursive self-modeling, niche construction, plasticity-stability.
2. **Content grows inside files.** Add examples, violations, and connections — but only within existing principle files.
3. **Principle file template:** Definition → Consequence → Application Examples → Typical Violations → Relationship to FPF.
4. **hierarchy.md** is the single source for the hierarchy map. Do not duplicate it in README.
5. **README** covers overview and navigation only. Do not duplicate principle content there.
