# Карта маршрутизации

> **Назначение:** единственное место, где записано, куда в твоём хранилище что класть и откуда что брать. По ней работают ИИ-помощники: размечают новый материал перед сессией стратегирования, записывают согласованное и собирают выборки («покажи всё по здоровью»).
> **Чья она:** твоя. Строки можно менять и добавлять; помощник дописывает новую строку, когда встречает материал, для которого дома нет, и спрашивает тебя, куда его класть. Образец с домами по умолчанию поставляет платформа.

## Ключевые места

| Место | Что там |
|---|---|
| `docs/Strategy.md` | стратегия: видение, цели на горизонт, принципы |
| `docs/Dissatisfactions.md` | неудовлетворённости |
| `docs/WP-REGISTRY.md` | реестр рабочих продуктов (РП): по строке на каждый |
| `inbox/WP-<номер>/WP-<номер>.md` | карточка РП: что делаем, фазы, что осталось |
| `current/` | план недели и план дня |
| `docs/Backlog.md` | отложенное с условием возврата: то, что не взято на неделю |
| `inbox/` и `inbox/fleeting-notes.md` | входящие: заметки на ходу и новые файлы до разбора |
| `docs/Routing-Map.md` | эта карта |

## Что куда класть

| Вид материала | Дом | Примечание |
|---|---|---|
| Цель (желаемый результат на месяц-год) | `docs/Strategy.md`, цели на горизонт | с пометкой области в квадратных скобках |
| Неудовлетворённость (что мешает, раздражает, разрыв с желаемым) | `docs/Dissatisfactions.md` | с пометкой области |
| Обязательство или предложение, взятое на неделю | план недели в `current/`; если это РП — карточка в `inbox/WP-<номер>/` и строка в `docs/WP-REGISTRY.md` | РП заводится только после твоего решения |
| Обязательство или предложение, не взятое на неделю | `docs/Backlog.md` | с областью и датой возврата |
| Отложенное при разметке | раздел «Разметка нового» плана недели, список «Отложено при разметке» | возвращается на следующую разметку |
| Заметка на ходу | `inbox/fleeting-notes.md` | разбирается на следующей сессии |
| Произошедшее, справка | остаётся там, где лежит | не переносится |
| Чужие личные данные, пароли и ключи, платёжные данные | не переносится и не цитируется | решение только твоё |

## Мои источники

> Свои файлы и папки в привычной тебе раскладке. Они остаются на месте: помощник читает их при разметке, а согласованное записывает в дома из таблицы выше.

| Источник | Что в нём | Как обращаться |
|---|---|---|
| _пример: `docs/projects-and-tasks.md`_ | _все проекты и задачи одним списком_ | _читать при разметке; не менять_ |

## Области

> Проекты и сферы жизни, которыми ты пользуешься для пометок. Одно написание на область — по нему собирается выборка.

- _пример: работа_
- _пример: здоровье_
