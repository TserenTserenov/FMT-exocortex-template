#### 5b. Линза калибра (lifework-пакет)

> Реализует Фазу 2b метода `PD.METHOD.008` (стратегирование). Алгоритм рекомендации Стратегом — `PD.METHOD.018` § Механизм рекомендации Стратегом. Три поля (V_scope/A_scope/D_scope) и запрет арифметики — `PD.FORM.091 §6.1`.

1. **Прочитай трекер:** `$GOV_WT/Lifework/Caliber-artifacts-tracker.md` (если файла нет — создай из шаблона `{{WORKSPACE_DIR}}/FMT-exocortex-template/templates/strategy-skeleton/Lifework/Caliber-artifacts-tracker.md`)
2. **Классифицируй видение → V_scope:** для каждого УСТОЙЧИВОГО НЭП — категория `PD.FORM.090` по проверочным вопросам `PD.FORM.091 §6.1` (1. Я — относится к самому человеку? 2. Ближний круг — к длительным близким отношениям? 3. Дальний круг — к команде/заказчикам/профессиональному кругу? 4. Сообщество — к устойчивому сообществу/направлению? 5. Общество — к институту/культуре/стране? 6. Человечество и поколения — к человечеству/будущим поколениям? FORM.027 9-10 сам по себе не даёт V_scope=6). V_scope = наивысшая достигнутая категория. Нет устойчивого НЭП ни по одной строке → `V_scope = unconfirmed`. Один НЭП подходит под несколько строк → статус `ambiguous`, уточнить диалогом
3. **Подтверди действие → A_scope:** max категория охвата (`PD.FORM.090`) с наблюдаемым произведённым изменением или принятой ответственностью (завершённые проекты, решения, внешние результаты, подтверждение Диагноста). Lifework-документ не обязателен для этой оценки. Подтверждённых действий ещё нет → `A_scope = unconfirmed` (не «ноль»)
4. **Проведи аудит документации → D_scope:** наивысшая категория со зрелым lifework-документом — зрелость по `PD.METHOD.018` § Условия подъёма (срок разный по переходу: ≥6 мес для 1→2 и 2→3, ≥1 года для 3→4 и 4→5, ≥3 лет для 5→6, не единый срок). Читай из `$GOV_WT/Lifework/` (там живут личные документы). Папки нет или пуста → `D_scope = none`; это НЕ повод сразу предлагать писать документ — первый объект работы для нового участника — безопасный обратимый личный проект уровня 1 и наблюдаемый след (действие, не документ); шаблон документа (`lifework-self-charter-template.md` из `PACK-personal/.../lifework-templates/`) предлагается только когда дошла очередь по шагу 7 ниже
5. **Проверь полноту нижних инвариантов D_scope** (`PD.FORM.090 §6`): все ли уровни 1..D_scope присутствуют? Поломки внизу → рекомендация «догнать вниз», STOP здесь (поломка наверху = обрыв снизу, приоритетнее подъёма)
6. **Сопоставь V_scope и A_scope → качественный статус** (порядковое сравнение на одной шкале, не арифметика): равны → `aligned`; V на одну категорию выше → `adjacent_frontier`; V на две+ категории выше → `vision_ahead`; A выше V → `action_ahead`; V_scope или A_scope = unconfirmed → `unconfirmed`; неоднозначная категория на шаге 2/3 → `ambiguous`
7. **Проверь локальную готовность к следующему документу** (`PD.METHOD.018` § Условия подъёма + § Локальный gate документа): предыдущий документ прошёл СВОЙ тестовый период по таблице «Условия подъёма» (не единый срок — см. шаг 4) И реальный паттерн следующей категории уже наблюдается в A_scope? Таблица также даёт качественные условия перехода (размер и устойчивость круга), не только срок. Ступень мастерства (`PD.FORM.080`) калибрует только объём поддержки — она не открывает и не закрывает эту готовность. При готовности — рекомендация документа смежной категории выше D_scope; иначе — рекомендация действия на текущем уровне, не документа
8. **Логика напоминания** (читая трекер):
   - `proposed` 1-я сессия → объяви рекомендацию как РП
   - `proposed` 2-я сессия → напомни: «всё ещё в зоне роста, поставим РП?»
   - `proposed` 3-я сессия → спроси частоту: создать сейчас / `remind_monthly` / `dismissed`
   - `remind_monthly` >4 недель → напомни «месяц назад: [X], изменилось ли?»
   - `dismissed` → не напоминать (возврат только при новом свидетельстве в V_scope, A_scope или D_scope)
   - `remind_monthly` >12 мес → авто-`dismissed`
9. **Не более одного up-level артефакта в фокусе.** Если в трекере уже есть `proposed`/`in-progress` документ категории выше D_scope — НЕ добавлять второй. Анти-имитация (`PD.FORM.091 §8` «Подмена видения созданием»)
10. **Обнови трекер** с датой сессии, V_scope/A_scope/D_scope, качественным статусом, статусом рекомендации, следующим ремайндером

**Антипаттерн:** «У тебя S0 в НЭП → давай напишем Конституцию Дела». Корректно: рекомендации идут от готовности (D_scope + локальный gate), не от видения (V_scope) напрямую. Высокий V_scope при низком A_scope/D_scope — нормальное состояние роста (статус `vision_ahead`), не повод для имитации.
