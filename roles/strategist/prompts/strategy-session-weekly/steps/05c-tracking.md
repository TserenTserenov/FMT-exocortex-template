# Step 05c: Калибр — запись решения

## ВДВ

| | |
|---|---|
| **Вход** | Решение пилота из шага 05b + текущий трекер |
| **Действие** | Обновить Caliber-artifacts-tracker, зафиксировать статус |
| **Выход** | Обновлённый трекер, следующий ремайндер запланирован |

## Инструкция для Claude

0. **Проверь согласие** перед записью — [../appendix/consent-check.md](../appendix/consent-check.md). При `denied`/`null` — НЕ писать трекинг/domain_event, идти на самодекларации.

1. **Обнови трекер** — тот `Caliber-artifacts-tracker.md`, который нашёл шаг 05a (п.1). Трекера нет (05a шёл на самооценке) — ничего не записывай и не создавай, скажи пилоту одной строкой:
   - Дата сессии
   - V_scope, A_scope, D_scope, качественный статус (из 05a)
   - Статус рекомендации: `proposed` / `remind_monthly` / `dismissed` / `in-progress` / `done`
   - Следующий ремайндер (дата или `null`)

2. **Если пилот решил создать РП** — добавь его кандидатом в пул этапа 8 (шаг 06a) с источником «калибр»; карточку не создавай: новые РП регистрируются только на этапе 10 через `/wp-new` (раздел «Регистрация РП перед утверждением» скилла `strategy-session`)

3. **Без отдельной остановки.** Это шаг «запись»: выполняется в начале хода сразу после решения пилота по шагу 05b. Пилоту — одна строка о том, что записано в трекер, затем в этом же ходе файлы следующего этапа по таблице («План недели: кандидаты»).
