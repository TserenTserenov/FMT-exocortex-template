# Step 05c: Калибр — трекинг

## ВДВ

| | |
|---|---|
| **Вход** | Решение пилота из шага 05b, маршрут калибра и, только для данных IWE, текущий трекер |
| **Действие** | Для данных IWE обновить Caliber-artifacts-tracker; для самооценки не писать персональный трекинг |
| **Выход** | Обновлённый трекер либо переход без записи, следующий ремайндер при наличии данных |

## Инструкция для Claude

0. **Сначала проверь маршрут:**
   - `пропуск` → этот шаг не выполняется; идти к 06a.
   - `самооценка` → не писать `Caliber-artifacts-tracker.md` и domain_event; при необходимости зафиксировать только обычное решение пилота в соответствующем РП, затем идти к 06a.
   - `по данным IWE` → перед записью проверь согласие по [../appendix/consent-check.md](../appendix/consent-check.md). При `denied`/`null` не писать трекинг/domain_event, сообщить `data_unavailable` и вернуться к выбору самооценки или пропуска.

1. **Только для маршрута «по данным IWE» обнови трекер** (`docs/Caliber-artifacts-tracker.md`):
   - Дата сессии
   - C_vis, C_act (из 05a)
   - Статус рекомендации: `proposed` / `remind_monthly` / `dismissed` / `in-progress` / `done`
   - Следующий ремайндер (дата или `null`)

2. **Если пилот решил создать РП** — сформируй WP-файл и включи в пул (шаг 06a)

3. **Вопрос пилоту:**
   > «Продолжить к формированию плана / скорректировать / пропустить?»
