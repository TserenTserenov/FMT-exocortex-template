# Step 03: Неудовлетворённости (НЭП)

## ВДВ

| | |
|---|---|
| **Вход** | `docs/Dissatisfactions.md` + новые сигналы из inbox (шаг 02) и нерегулярных блоков (шаг 07) |
| **Действие** | Закрыть разрешённые НЭП, обсудить новые, обновить Dissatisfactions.md |
| **Выход** | Актуализированный Dissatisfactions.md, решения по новым НЭП |

## Инструкция для Claude

1. **Прочитать** `docs/Dissatisfactions.md`

   **Файла нет или он пуст** → это пустой вход (`extensions/strategy-cycle/SPEC.md` §5), не ошибка сборки: пропусти шаги 2-3, в выходе явно отметь «НЭП-блок пуст (файла нет)» — отличай этот случай от «файл есть, но данные не собраны» (например, пилот не вёл реестр эту неделю), который отмечай отдельной пометкой «НЭП-блок не актуализирован», не молчаливым пропуском.

2. **Проверить:**
   - Какие операционные НЭП разрешены (можно закрыть)?
   - Есть ли стратегические НЭП без привязки к РП на этой неделе?
   - Новые НЭП из inbox / нерегулярных блоков
   - **Стареющие без движения 8+ недель** (по дате последнего изменения записи в `Dissatisfactions.md`) — собери отдельным списком, не пропускай молча

3. **Обсудить с пилотом:**
   - Закрыть разрешённые
   - Сформулировать новые
   - Проверить привязку к РП
   - **По каждой стареющей записи — принудительный выбор пилота:** закрыть / переформулировать / оставить с явным триггером пересмотра (не «оставить как есть» без даты или события — это и есть повторное старение)

4. **Обновить** `Dissatisfactions.md` по решениям пилота

5. **Вопрос пилоту:**
   > «Продолжить к стратегической сверке / скорректировать / пропустить?»
