# Step 05a: Калибр — измерение

## ВДВ

| | |
|---|---|
| **Вход** | Выбранный пилотом маршрут калибра; для маршрута «по данным IWE» — трекер, НЭП и Lifework |
| **Действие** | Выбрать: самооценка / по данным IWE / пропуск; только для данных IWE вычислить C_vis, C_act, разрыв и пакет |
| **Выход** | Пропуск либо измерения + рекомендация для шага 05b |

## Инструкция для Claude

> Метод: `PD.METHOD.018` § Механизм рекомендации Стратегом. Различение C_vis vs C_act — `PD.FORM.091 §6.1`.

1. **Сначала спроси пилота:**
   > «Нужен ли сегодня калибр: самооценка, по данным IWE или пропустить?»
   **СТОП — жди выбора.** До выбора не читай трекер, НЭП, Lifework и не запрашивай согласие.

2. **Маршрутизируй выбор:**
   - `пропустить` → сообщи, что калибр не проводится, и перейди к шагу 06a. Ничего не читай и не записывай.
   - `самооценка` → попроси пилота назвать C_vis и C_act; не читай персональные файлы и не записывай трекинг. Покажи разрыв и перейди к шагу 05b только для обсуждения рекомендации.
   - `по данным IWE` → до чтения проверь согласие по [../appendix/consent-check.md](../appendix/consent-check.md). При `denied`/`null` или недоступных данных сообщи `data_unavailable` и предложи самооценку или пропуск; **СТОП — жди выбора.**

3. **Только для маршрута «по данным IWE»: прочитай трекер** `docs/Caliber-artifacts-tracker.md` (если нет — создай из шаблона)

4. **Измерить C_vis:**
   - Max системный уровень в `Dissatisfactions.md` с фильтром «≥2 НЭП на уровне»
   - Одиночный НЭП на высоком уровне = сигнал, не калибр видения

5. **Измерить C_act:**
   - Max уровень охвата (`PD.FORM.090`) с lifework-документом, действующим ≥6 мес
   - Читай из `Lifework/` (если нет — C_act=0)

6. **Объяви разрыв:** «C_vis=N, C_act=M, зона роста = [M+1..N]»

7. **Проверь минимально полный пакет уровня C_act:**
   - Все инварианты уровней 1..C_act присутствуют?
   - Поломки внизу → рекомендация «догнать вниз», STOP

8. **Двойной gate для подъёма:**
   - Активируй рекомендацию уровня C_act+1 ТОЛЬКО если:
     - (а) пакет C_act полный + действует ≥6 мес
     - (б) ступень мастерства ≥3 (`PD.FORM.080`)
   - Иначе фокус на текущем уровне

9. **Выведи результаты** (C_vis, C_act, разрыв, рекомендация) пилоту. **СТОП — жди следующего сообщения. Не читать файл шага 05b до следующего хода.**
