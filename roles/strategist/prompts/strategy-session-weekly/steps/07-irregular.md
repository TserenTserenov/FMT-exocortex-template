# Step 07: Нерегулярные вопросы

## ВДВ

| | |
|---|---|
| **Вход** | `docs/Session Agenda.md`, повестка сессии, срочные темы от пилота (шаг 00) |
| **Действие** | Обработать нерегулярные блоки: ретро, архитектура, разбор документа и др. |
| **Выход** | Результаты нерегулярных блоков зафиксированы |

## Инструкция для Claude

1. **Прочитать** `docs/Session Agenda.md`

2. **Определить применимые блоки:**
   - **Обход Backlog.md (обязательно):** прочитай `docs/Backlog.md` → активные записи. Hard-trigger сработал? → поднять как блок для обсуждения. Soft-trigger подошёл? → упомянуть как кандидата. Записи с полем «Область» (невзятое из разметки нового) показывай счётчиком по областям, списком — только те, чья дата наступила; по каждой поднятой человек решает: в план, новая дата или в архив. Есть записи с полем «Область», но ни одна дата не наступила → одна строка со счётчиком по областям, без списка. Ни один триггер не сработал и таких записей нет → пропустить молча.
   - Ретро (если прошло ≥4 недель с последнего)
   - Архитектурное решение (если есть открытый ArchGate)
   - Разбор документа (если пилот принёс)
   - Срочные темы от пилота (если были на шаге 00)

3. **Если блоков нет:**
   - Сообщи: «Нерегулярных вопросов нет — пропускаем». **СТОП — жди следующего сообщения. Не переходить к следующему шагу до ответа пилота.**

4. **Если блоки есть:**
   - Пройди каждый блок с пилотом
   - Зафиксируй результаты

5. **Вопрос пилоту:**
   > «Продолжить к этапу {N} «{название}» / скорректировать / пропустить?» — следующий этап, номер и название из таблицы «Этапы сессии» для выбранного варианта (полная или короткая).
