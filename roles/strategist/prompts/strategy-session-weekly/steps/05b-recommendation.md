# Step 05b: Калибр — рекомендация

## ВДВ

| | |
|---|---|
| **Вход** | Измерения из шага 05a (V_scope, A_scope, D_scope, качественный статус, `ready_for_next_document`) |
| **Действие** | Объявить рекомендацию роста, предложить РП |
| **Выход** | Решение пилота: создать РП / remind_monthly / dismiss |

## Инструкция для Claude

1. **Объяви рекомендацию документа смежной категории выше D_scope** (только если `ready_for_next_document: true` из шага 05a). Если `false` — сформулируй рекомендацию действия, укрепляющего текущий паттерн, не документ.

2. **Логика напоминания** (читая трекер):
   - `proposed` 1-я сессия → объяви рекомендацию как РП
   - `proposed` 2-я сессия → напомни: «всё ещё в зоне роста, поставим РП?»
   - `proposed` 3-я сессия → спроси частоту: создать / `remind_monthly` / `dismissed`
   - `remind_monthly` >4 недель → напомни «месяц назад: [X], изменилось ли?»
   - `dismissed` → не напоминать (возврат только при новом свидетельстве в V_scope, A_scope или D_scope)
   - `remind_monthly` >12 мес → авто-`dismissed`

3. **Не более одного up-level артефакта в фокусе**
   - Если в трекере уже есть `proposed`/`in-progress` документ категории выше D_scope — НЕ добавляй второй
   - Анти-имитация (`PD.FORM.091 §8` «Подмена видения созданием»)

4. **Антипаттерн:** «У тебя S0 в НЭП → давай напишем Конституцию Дела». Корректно: рекомендации идут от готовности (D_scope + локальный gate), не от видения (V_scope) напрямую.

5. **Вопрос пилоту:**
   > «Продолжить к трекингу калибра / скорректировать / пропустить?»
