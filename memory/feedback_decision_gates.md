# Правило проектирования gate-критериев

**Правило:** решающий критерий gate'а формулируется как **бинарный множественный выбор yes/no** со списком тестов, каждый с явным определением «выполняет». Решение — **все тесты = «выполняет»** (или критерий ArchGate-образного: фиксированный набор обязательных признаков). Любое «нет» или «непонятно» блокирует.

**ЗАПРЕЩЕНО:**
- **Проценты** («>30% cross-links», «<20% overlap»).
- **Веса** («T1=3, T2=2; порог ≥6»).
- **Score-пороги** («score ≥5 → создать»).
- **«N из M» без обоснования** («3 из 4 тестов»).

**Why:** Количественные пороги (проценты, веса, score) без калибровки на истории — дым. Числа берутся «из головы», применяются произвольно, не ловят то, что должны ловить. Качественный бинарный чеклист с явным определением «выполняет» для каждого пункта — применим одинаково всеми, проверяем постфактум. ArchGate — эталон: ЭМОГССБ + чёткий порог-таблица (а не «пара баллов»).

**How to apply:**
- При проектировании нового gate'а (gate в смысле решающего правила: нужен ли новый Pack / Pack-кандидат проходит / архитектурное решение принимается):
  1. Сформулировать тесты как **утверждения с бинарным ответом**.
  2. Для каждого теста написать **определение «выполняет»** (что именно делает ответ «да»).
  3. Зафиксировать **решающее правило** как конъюнкцию («все → да») или явный паттерн обязательных/необязательных (как в ArchGate).
- При ревью старых правил: если видишь проценты / веса / scores — переписать в бинарный чеклист или убрать.
- Если количественный порог всё-таки нужен (редко) — требовать в ADR: (а) источник числа (калибровка на истории), (б) что именно этот порог отсекает, (в) дата следующей калибровки.

**Пример (Pack creation, 4 теста):**
- T1: у кандидата есть отдельный главный вопрос, не сводящийся к соседнему Pack.
- T2: есть минимум один тип work-product, которого нет в соседних Pack.
- T3: есть минимум одна пара различений, несводимая к соседнему Pack.
- T4: словарь определён локально, без заимствования без ACL.
- Решающее правило: все 4 = «выполняет» → новый Pack. Иначе — раздел или черновик.
