# Repository type

**Type**: `Base/Formats`
**System (SoI)**: cross-cutting
**Content**: text description
**Audience**: public
**Source of truth**: yes, for the IWE format

## Upstream dependencies

- FPF (First Principles Framework)
- SPF (Second Principles Framework)

## Downstream outputs

- User forks (personal IWE workspaces)
- DS-exocortex-setup (installation agent)

## Non-goals

- Storing domain knowledge (a Pack owns that)
- Storing personal user data (the user's workspace owns that after forking)
- Bot and service code (separate downstream repositories own that)
