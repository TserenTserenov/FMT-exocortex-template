# IWE 0.42

Первый выпуск, который вышел через проверенную сборку-кандидат: до пользователей доходит ровно та сборка, которую проверили тестировщики и независимая атака. Прошлый выпуск — 0.41.11. Полный список изменений — раздел `[0.42.0]` в [CHANGELOG.md](../../../CHANGELOG.md); здесь только главное.

## Что нового

- **Поиск метода** — навык `/find-method` (экспериментальный). Опишите затруднение, и агент подберёт способ действия из FPF и ваших паков, покажет дословный фрагмент источника и проведёт по шагам. Если подходящего метода нет, он так и скажет, а не придумает план.
- **Лёгкий онбординг** — навык `/onboarding`. Новый человек за один разговор разбирает свою задачу методом из библиотеки и в правила рабочей среды не попадает.
- **Уведомления в Telegram** идут через одну команду `scripts/iwe-notify`. Можно подключить свой шлюз уведомлений: тогда рутинные сообщения собираются в сводку.
- **Linux и WSL2.** Установка снова ставит фоновые роли (Стратег, разборщик) службами `systemd --user` или через cron, без ручной настройки.
- **Агенту запрещено больше опасного.** Проверка опасных команд не даёт агенту без вашего участия:
  - удалять найденное через `find` или `xargs`;
  - писать в файл через `git diff --output` и `find -fprint`;
  - запускать через `find -exec` что-либо, кроме чтения;
  - удалять ветки и менять адрес хранилища через `git branch` и `git remote`;
  - затирать файлы защитных проверок.
- **Обновление надёжнее:**
  - доставленные программы получают право на запуск, как на чистой установке;
  - возврат на прошлый выпуск всегда спрашивает `ROLLBACK`, на любом канале;
  - после возврата файлы более нового выпуска убираются в резервную копию.

## Как обновиться

```bash
cd ~/IWE/FMT-exocortex-template
bash update.sh --check     # что изменится и можно ли ставить: строка «ВЕРДИКТ»
bash update.sh             # применить
```

Или попросите агента: `/iwe-update`. Он объяснит изменения простыми словами и поможет со своими правками.

Ваши расширения (`extensions/`), `params.yaml` и свои правки файлов обновление сохраняет.

## Как вернуться на 0.41.11

Обновление, которое вернёт установку на более старый выпуск, называет это откатом и ждёт, пока вы введёте `ROLLBACK`. С ключом `--yes` откат не выполняется никогда. После подтверждения:

- установка совпадает с 0.41.11;
- файлы, которые были только в 0.42 и которые вы не меняли, переносятся в `.backups/deprecated/`;
- изменённые вами файлы остаются на месте, и вывод их называет.

## Известные ограничения

- **Агент может прочитать ваши секреты без запроса.** Команды чтения разрешены без подтверждения: `cat`, `git show` и другие. Поэтому агент может прочитать файл с ключами, например `.env`, внутри папки IWE. Ключи храните вне папки IWE, например в `~/.secrets/`, и не просите агента их показывать. Это было и в 0.41.11, исправление готовится отдельно.
- **Проверка опасных команд видит только текст команды.** Путь, спрятанный в переменную, она не распознаёт. Это последний рубеж, а не замена вашему вниманию к тому, что агент предлагает запустить.
- **macOS и Windows.** Сборку проверили программы на серверах GitHub (macOS, Windows, Linux) и вручную на Linux. Ручная проверка на macOS идёт; если она что-то найдёт, пункт появится здесь.
