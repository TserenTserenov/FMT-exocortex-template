# IWE 0.42: что нового и как этим пользоваться

**Коротко.** Познакомиться с IWE на своей задаче теперь можно за один разговор: для этого знакомства не нужны аккаунт и подписка МИМ. Появился пробный навык, который подбирает метод под ваше затруднение. Исправлены причины, мешавшие обновлению и пробному прогону в Git Bash на Windows. IWE теперь останавливает команду агента, которая ищет файлы и сразу их стирает. И много исправлений в закрытии дня и сессий, разборе знаний и английской версии.

**Как обновиться.** Скажите своему Claude «обнови мой экзокортекс» (так помощник называет вашу папку IWE) или выполните в терминале `bash update.sh`. Большинство изменений начинает работать сразу после обновления. Кому нужно что-то поменять самим — в последнем разделе.

### Начать с IWE за один разговор

**Что теперь можно.** Новый человек может попробовать IWE на своей задаче за один разговор. Помощник разберёт её подходящим методом из библиотеки на вашем компьютере, а в конце соберёт итог «было → стало» из ваших же слов. Для этого знакомства не нужны аккаунт и подписка МИМ; хранение прогресса и подключаемые услуги — отдельно. Со страниц знакомства убраны разговоры о подписке и ценах, в быстрый старт добавлен шаг «попробовать метод на своей задаче».

**Как пользоваться.** Откройте новый разговор с Claude в папке IWE и напишите `/onboarding` — или просто спросите «с чего начать?» и расскажите, что сейчас тормозит.

**Пример запроса.** «/onboarding — у меня постоянно срываются сроки по проекту, хочу разобраться почему».

### Подобрать метод под своё затруднение (пробная версия)

**Что теперь можно.** Навык `/find-method` ищет способ действия под вашу ситуацию в библиотеках на вашем компьютере — в своде принципов и в ваших собственных базах знаний. Он показывает подходящие методы с цитатой из источника и ведёт по шагам выбранного. Шаги показываются дословно, на языке источника (часто английском), русское пояснение идёт после цитаты. Если метода нет или в источнике есть только описание без пошаговой инструкции, навык так и говорит. Для поиска он использует только библиотеки на вашем компьютере и не обращается к сети и платным инструментам.

**Как пользоваться.** Напишите `/find-method` и опишите затруднение своими словами.

**Примеры.**
- «/find-method нужно ли мне исследование, чтобы ответить на мой вопрос, или хватит того, что уже известно» — навык предложит метод исследования, после выбора покажет все его восемь шагов.
- «/find-method как вывести закваску для хлеба» — на стандартных библиотеках ответит, что метода нет.

### Обновление

- **Git Bash на Windows:** исправлена причина, из-за которой обновление останавливалось после первого записанного файла.
- Если обновление не смогло безопасно обновить ваш `CLAUDE.md`, оно больше не выдаёт его за обновлённый — сверьте его по подсказке обновления.
- Навык разбора кандидатов знаний (`apply-captures`) больше не падает на шагах 1 и 6, а проверку на дубли делает по вашей собственной базе знаний.
- Можно не добавлять новый рабочий продукт в план недели автоматически: строка `wp_new_add_to_weekplan: false` в файле настроек `params.yaml`. По умолчанию всё как раньше.

### Проверка установки и пробный прогон

- **Git Bash на Windows:** исправлено, из-за чего пробный прогон нельзя было начать.
- Проверка установки (`/audit-installation`) больше не требует дописывать путь вручную, а проверку GitHub без подписки показывает паузой, а не ошибкой.
- Закрытие дня в пробном прогоне больше не останавливается на подсчёте памяти.
- Подсчёт памяти стал быстрее на большой памяти, а файлы без даты больше не пропускаются молча — они перечислены в отчёте.
- Проверка свежести репозиториев больше не падает на обычной установке.
- В пробном прогоне строже блокируется запуск скриптов по пути и запись через инструменты IWE и Google Calendar в Kimi Code.
- На macOS утреннее и недельное планирование после обновления не запускаются второй раз рядом с общим планировщиком.

### Безопасность

- **Меньше риска потерять файлы.** Раньше агент мог одной командой найти файлы и сразу их стереть (например, `find … -delete` или `find … -exec rm`), и IWE его не останавливал. Теперь такая команда останавливается до выполнения, а агент получает объяснение. Обычный поиск файлов работает как раньше.
- **Как это выглядит.** Вы просите «почисти временные файлы в папке проекта», агент пробует найти их и сразу стереть одной командой — IWE эту команду не выполняет и сообщает агенту причину. Файлы остаются на месте.
- Если список правил безопасности не читается, агент получает отказ с причиной, а не тихо работает без проверок.

### Сессии и рабочие продукты

- **«Заливай» больше не закрывает сессию:** агент сохраняет и отправляет изменения, а закрывает по «закрывай» или «заливай и закрывай». Слово в кавычках («я не писал "закрывай"») командой не считается.
- Закрытие сессии больше не падает, если её изменения уже были отправлены раньше.
- Открытие и закрытие дня снимают только свою отметку и не трогают отметку параллельной сессии.
- При открытии рабочего продукта входящие записи сверяются по серверу, а не по устаревшей копии.

### Разбор знаний

- Исправлена ошибка, из-за которой два одновременных разбора знаний мешали друг другу.
- Если на установке нет файла проверки публикации, результат разбора сохраняется у вас, а уведомление просит обновиться. После обновления следующий прогон отправит сохранённое или разберёт заметки заново.

### Уведомления в Telegram

- Все сообщения шаблона в Telegram теперь отправляются одной командой. На обычной установке они по-прежнему приходят прямо в Telegram.

### Linux и WSL2

- Установка снова сама ставит фоновые роли (например, утреннее планирование): они выбирают systemd или cron. Если планировщика нет, установка не обрывается, а называет команду, чтобы поставить роль позже.

### WakaTime

- WakaTime перестал принимать ключ плагина для сводок. Время за сегодня скрипт берёт другим запросом, а за прошлые дни без личного токена показывает причину вместо числа.
- **Как вернуть время за прошлые дни:** получите личный токен на https://wakatime.com/oauth и задайте его в переменной окружения `WAKATIME_OAUTH_TOKEN`. Можно сказать своему Claude «/setup-wakatime» — навык подскажет шаги. Сам токен в чат не присылайте.

### Английская версия

- Перевод шаблона на английский снова доходит до публикации. Термины берутся из общего словаря, а новые английские термины без утверждения переводчик перечисляет в отчёте.
- `IWE_LANG=en` включает английские сообщения проверки закрытия сессии и переведённые элементы плана дня; проверка понимает и английские фразы закрытия.

### Кому нужно что-то поменять самим

- **Время WakaTime за прошлые дни** — задать личный токен (раздел «WakaTime»).
- **Российские ссылки в знакомстве с IWE** — добавить строку `region: ru` в `params.yaml`; без неё используются ссылки aisystant.com.
- **Свой языковой каталог** (если вы его делали) — добавить ключи `recognition.push_only` и `agent.close_gate.push`, иначе проверка закрытия его не загрузит.
- **`CLAUDE.md`, который обновление не тронуло** — сверить вручную по подсказке обновления.
- **Linux и WSL2, если роли раньше не установились** — выполнить команду установки роли, которую называет установка.

Все записи выпуска — в [журнале изменений шаблона, раздел 0.42.0](https://github.com/TserenTserenov/FMT-exocortex-template/blob/v0.42.0/CHANGELOG.md). Другие выпуски — в [списке выпусков](README.md).
