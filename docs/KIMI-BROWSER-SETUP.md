# Браузерный доступ к IWE через стенд МИМ

> Для кого: новичок без VS Code и без Claude — хочет попробовать IWE прямо в браузере.
> Время: ~2 минуты.
> Отличие от `KIMI-SETUP.md`: тот документ — про Kimi Code внутри VS Code (для тех, кто уже кодит и клонировал репозиторий). Этот — про отдельный браузерный стенд, ничего устанавливать не нужно.

## Что получится

- Откроете веб-страницу с чатом.
- Зададите вопрос — помощник найдёт ответ в базе знаний и памяти платформы IWE, так же как Claude через свой браузерный коннектор.
- Один раз войдёте через свой аккаунт платформы — дальше помощник видит только ваши личные данные, не данные других участников.
- Будете пользоваться стендом по подписке платформы. Отдельный ключ поставщика модели не нужен.

## Почему нужны вход и подписка

В отличие от Claude, который умеет напрямую подключаться к платформе через коннектор, некоторым моделям нужна отдельная веб-страница. Поэтому IWE предоставляет стенд МИМ. Он использует тот же вход, что и остальные каналы платформы: после входа помощник получает доступ к поиску по базе знаний и вашей личной памяти, но видит только ваши данные.

Ответы модели оплачиваются через подписку платформы. Стенд проверяет подписку автоматически; вставлять ключ Moonshot, OpenRouter или другого поставщика не нужно.

## Как подключиться

1. Откройте [стенд МИМ](https://mim-iwe-production.up.railway.app).
2. Нажмите кнопку входа.
3. Если у вас уже есть аккаунт — войдите обычным способом. Если нет — на той же странице можно зарегистрироваться.
4. При действующей подписке откроется чат — можно сразу писать вопрос. Если подписки нет, стенд покажет понятное сообщение вместо технической ошибки.

## Что можно спрашивать

- Вопросы про устройство и принципы IWE («что такое ОРЗ-фрактал», «как устроена память платформы»).
- Вопросы, требующие поиска по базе знаний платформы.

Помощник отвечает не мгновенно — на вопрос, требующий поиска, может уйти до минуты. Если ответ не пришёл за отведённое время, страница предложит переформулировать вопрос короче или конкретнее — это нормально, не ошибка.

## Если что-то не работает

1. Страница показывает кнопку входа снова после того, как вы уже вошли — попробуйте перезайти, возможно истекло время сессии в браузере.
2. Ответ долго не приходит или пришла ошибка сети — обновите страницу и попробуйте задать вопрос ещё раз.
3. Если вход не удаётся — обратитесь к ведущему занятия или администратору платформы.
4. Если стенд сообщает, что нет активной подписки, проверьте подписку платформы или обратитесь к администратору.
