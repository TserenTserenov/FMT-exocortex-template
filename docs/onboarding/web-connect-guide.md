# Connect Aisystant Open in a browser

[Aisystant Open](https://aisystant.com/connect#guest) gives an AI chat read-only access to the public FPF Library. You can connect it to ChatGPT or Claude without an Aisystant account.

Follow the current [connection steps](https://aisystant.com/connect) for your client. The server address is `https://open.aisystant.com/mcp`.

This public connection does not include your private IWE files or personal profile. For a local English IWE workspace in VS Code, use the [VS Code setup guide](https://aisystant.com/connect#vscode).
