## Операционная система интеллектуальной работы

---

# Ядро мышления — чем думаешь

| Что | Зачем | Откуда |
|-----|-------|--------|
| **Теории** | Системное мышление, методология, менеджмент | Курсы Мастерской инженеров-менеджеров |
| **Экзокортекс** | Твоя вторая память. ИИ читает и обновляет | Дистрибутив IWE |
| **Pack** | Структурированная база знаний по домену | Создаёшь ты |

> Теории встроены в правила ИИ (принципы ZP → FPF). Ты изучаешь те же теории → одни принципы на двоих.

---

# Культура работы — как работаешь

| Тип | Что это | Примеры |
|-----|---------|---------|
| **Протоколы** | Делаешь по шагам | ОРЗ, АрхГейт, Day Open/Close |
| **Навыки** | Нарабатываешь практикой | Capture, Self-correction, различения |
| **Форматы** | Оформляешь по стандарту | Pack-структура, WP-context |

> Культура работы — это то, за что платят. Инструмент можно скопировать. Поставленную культуру — нельзя.

---

# Инструменты (средства доставки)

| Что | Зачем | Аналогия |
|-----|-------|----------|
| **Claude Code** | ИИ-ассистент, который читает твои файлы и помнит контекст | Напарник, а не поисковик |
| **VS Code** | Бесплатный редактор — пишешь обычные тексты | Блокнот, но умнее |
| **GitHub** | Облачное хранилище с полной историей изменений | Google Drive + машина времени |
| **Бот @aist_me_bot** | Помощник в Telegram: вопросы, напоминания | Наставник в кармане |

> Инструменты — не IWE. Это средства доставки четырёх компонентов. Как железо, на котором работает ОС.

# Твоя проблема

## (и она реальна)

---

# Знания теряются

- Читаешь книгу → делаешь заметки → через месяц не находишь
- Notion, блокнот, телефон, салфетка — **везде и нигде**
- Нет структуры, нет связей между идеями
- Каждый раз «начинаешь сначала»

---

# Планы не работают

- Составляешь план на неделю → к среде он неактуален
- Новые задачи вытесняют старые
- Нет ревью → ощущение «ничего не успеваю»
- Нет системы приоритетов

---

# ИИ не помогает по-настоящему

- ChatGPT / Claude дают красивые, но **общие** ответы
- Каждый раз начинаешь **с нуля**
- ИИ не знает: твои проекты, цели, что ты уже пробовал
- Это как разговаривать с новым человеком каждый день

---

<!-- _class: accent -->

# Как IWE это решает

---

# Проблема → Решение

| Проблема | Компонент IWE | Как |
|----------|--------------|-----|
| Знания теряются | **Ядро мышления** (экзокортекс + Pack) | Каждая единица знания — на своём месте. История в GitHub |
| Планы не работают | **Культура работы** (ритуалы ОРЗ) | Утром план, вечером итоги, еженедельно ревью |
| ИИ не помогает | **Ядро + культура** (Claude Code + экзокортекс) | Читает ТВОИ файлы, знает ТВОИ цели, помнит ТВОЮ историю |

# Шаг 2. Установка (~20 мин)

**Тебе не нужно уметь программировать.**

Три действия:
1. Установить VS Code и Claude Code *(бесплатно)*
2. Создать аккаунт на GitHub *(бесплатно)*
3. Запустить одну команду

> **ИИ поможет.** Скажи Claude Code: «Помоги мне установить IWE» — он проведёт через каждый шаг.

*Подробная инструкция: SETUP-GUIDE.md*

---

# Шаг 3. Первая сессия (~30 мин)

После установки ты:

- Заполняешь стратегический документ *(кто ты, что важно, куда двигаешься)*
- Формулируешь 3-5 задач на ближайшую неделю
- ИИ структурирует это в план

> Это не абстрактное упражнение — ты сразу получаешь работающий план.

---

# Шаг 4. Ежедневная практика

Каждый день — один ритм:

| Время | Действие | Что происходит |
|-------|----------|---------------|
| **Утро** | «Открой день» | Claude показывает план, события, контекст |
| **Работа** | Работаешь | Фиксируешь выводы на рубежах |
| **Вечер** | «Закрой день» | Claude записывает итоги, обновляет планы |

> Через неделю: ничего не теряется. Всё на своих местах.

# Не бойся

---

# «Я не программист»

Ты и не должен быть.

- VS Code — просто удобный редактор для **текстов**
- GitHub — просто надёжное **хранилище**
- Ты **не будешь** писать код

> IWE — ОС для интеллектуальной работы, не для программирования.

---

# «GitHub, CLI, терминал — это страшно»

Только в первый раз.

| Термин | Что это на самом деле |
|--------|----------------------|
| **GitHub** | Google Drive с историей изменений |
| **Терминал** | Окно, куда вводишь текст (Claude подскажет что) |
| **CLI** | Общение с компьютером текстом вместо кнопок |

> После установки ты общаешься с Claude Code **на русском языке**.

---

# Это не монолит — это конструктор

Путь подключения IWE — добавляй компоненты по мере надобности:

| Этап | Что подключаешь | Что получаешь |
|------|----------------|---------------|
| **Этап 1** | Claude Code + экзокортекс | ИИ-ассистент, который тебя помнит |
| **Этап 2** | + ритуалы ОРЗ | Структурированная работа |
| **Этап 3** | + Pack + бот | База знаний + мобильный доступ |
| **Этап 4** | + роли + автоматизация | ИИ-агенты работают самостоятельно |

> Это сборка локальной среды, не тир доступа (T0→T4, DP.ARCH.002) и не ступень мастерства (FORM.089).

# Теории и культура работы

## Фундамент, который работает для обоих — тебя и ИИ

---

# За инструментом стоят теории

| Теория | Что даёт | Где в IWE |
|--------|---------|-----------|
| **Системное мышление** | Видеть целое, а не части | Планирование, различения |
| **Методология** | Описания методов, рабочие продукты | ОРЗ, форматы, Pack |
| **Менеджмент** | Роли, лидерство, стратегирование | Роли, стратегические сессии |
| **Инженерия предприятия** | Как устроены организации | Архитектура, интеграции |

> Курсы: [Мастерская инженеров-менеджеров](https://system-school.ru/) — «Системное саморазвитие», «Системное мышление», «Методология».

---

# Четыре уровня принципов

| Уровень | Кто создаёт | Кто использует | Пример |
|---------|-------------|---------------|--------|
| **Нулевые (ZP)** | IWE | Ты + ИИ | Базовые правила мышления |
| **Первые (FPF)** | IWE | Ты + ИИ | Фреймворк, различения |
| **Вторые (Pack)** | **Ты** | Ты + ИИ | Твои знания по домену |
| **Третьи (DS)** | Ты + ИИ | Ты + ИИ | Планы, код, процессы |

> Принципы текут **сверху вниз** (от нулевых к третьим). Знания — **снизу вверх** (от твоего опыта обратно в Pack).

---

# Системное мышление = результат теорий + культуры

Умение видеть **целое**, а не только части.

| Без | С теориями и культурой работы |
|-----|-------------------------------|
| Неделя = список задач | Неделя = связанные задачи с приоритетами |
| Книга = конспект цитат | Книга = принципы для разных контекстов |
| ИИ = случайные вопросы | ИИ = точные запросы на основе структуры |

> Системное мышление — не предмет для зубрёжки. Это **результат** изучения теорий и применения культуры работы на практике в IWE.
