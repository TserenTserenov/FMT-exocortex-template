# Живая проверка раздачи подзадач нескольким агентам

Раздача независимых подзадач нескольким агентам (навык `/peer-fanout`) входит в выпуск 0.43 только после того, как её на своей установке проверит человек, который **не** автор шаблона. Если такой проверки нет к выпуску, схема переносится в 0.44.

Проверка занимает около пяти минут и тратит три обычных вызова Claude по вашей подписке.

## Что нужно заранее

- Чистая установка IWE версии 0.43 (кандидат выпуска) на macOS или Linux.
- Установленный и авторизованный Claude Code: команда `claude` в терминале открывает Claude без просьбы войти.
- Kimi, Codex и другие агенты **не** нужны.

## Шаг 1. Открыть терминал

На macOS: нажмите Cmd+Пробел, напишите `Терминал`, нажмите Enter. Откроется окно с мигающим курсором.

На Linux: откройте приложение «Терминал» из меню приложений.

Можно и в VS Code: меню «Терминал» → «Новый терминал»; панель терминала откроется внизу окна.

## Шаг 2. Создать папку для проверки

Вставьте эту команду в терминал и нажмите Enter:

```bash
export FANOUT_DIR=$(mktemp -d "${TMPDIR:-/tmp}/fanout-check.XXXXXX"); echo "$FANOUT_DIR"
```

Терминал напечатает путь к новой пустой папке (например, `/tmp/fanout-check.Ab12Cd`). Окно терминала до конца проверки не закрывайте: следующие команды используют эту папку.

## Шаг 3. Записать три подзадачи

Вставьте эту команду в тот же терминал и нажмите Enter:

```bash
printf '%s\t%s\t%s\n' a claude "Назови одну столицу Европы и одну её достопримечательность." b claude "Назови одну реку Азии и страну, по которой она течёт." c claude "Назови одно животное Австралии и чем оно питается." > "$FANOUT_DIR/t.tsv"; cat "$FANOUT_DIR/t.tsv"
```

Терминал покажет три строки: в начале каждой буква `a`, `b` или `c`, затем слово `claude` и текст вопроса.

## Шаг 4. Найти программу раздачи

Вставьте эту команду в тот же терминал и нажмите Enter:

```bash
FANOUT="${IWE_SCRIPTS:-${IWE_WORKSPACE:-$HOME/IWE}/scripts}/peer-fanout.sh"; [ -f "$FANOUT" ] || FANOUT="${IWE_TEMPLATE:-${IWE_WORKSPACE:-$HOME/IWE}/FMT-exocortex-template}/scripts/peer-fanout.sh"; ls -l "$FANOUT"
```

Терминал покажет одну строку с путём, который заканчивается на `peer-fanout.sh`. Если вместо этого написано `No such file or directory`, установка не 0.43: остановитесь и сообщите об этом в запросе на слияние.

## Шаг 5. Запустить раздачу

Вставьте эту команду в тот же терминал и нажмите Enter:

```bash
bash "$FANOUT" --tasks "$FANOUT_DIR/t.tsv" --out-dir "$FANOUT_DIR/out"; echo "exit=$?"
```

Подождите от нескольких секунд до пары минут: три агента отвечают одновременно, вопросов программа не задаёт. В конце терминал напечатает таблицу из трёх строк (колонки `id`, `vendor`, `status`, `bytes`, `elapsed_s`), строку вида `ok=3 total=3 out_dir=... wall_s=...` и последнюю строку `exit=0`.

Если появилась строка `PREFLIGHT FAIL: CLI 'claude' not found in PATH`, терминал не видит Claude Code: вернитесь к разделу «Что нужно заранее».

## Шаг 6. Посмотреть ответы

Вставьте эту команду в тот же терминал и нажмите Enter:

```bash
for f in a b c; do echo "== $f"; cat "$FANOUT_DIR/out/$f.md"; done
```

Под каждой строкой `== a`, `== b`, `== c` появится ответ на свой вопрос: столица, река, животное.

## Проверка пройдена, если выполнено всё сразу

1. Последняя строка шага 5 — `exit=0`.
2. Строка сводки начинается с `ok=3 total=3`.
3. Все три ответа из шага 6 непустые и отвечают на свои вопросы.
4. Число после `wall_s=` меньше суммы трёх чисел в колонке `elapsed_s`: подзадачи шли одновременно, а не по очереди.
