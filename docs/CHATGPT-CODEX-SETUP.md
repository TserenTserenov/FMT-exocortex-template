# Подключение IWE к ChatGPT и Codex

> Для кого: пользователь, который хочет получить доступ к базе знаний и инструментам IWE (Aisystant MCP) из ChatGPT (личный или рабочий аккаунт) или из локального Codex — без установки полного шаблона экзокортекса.
> Время: 10-15 минут.
> Общий принцип OAuth-подключения любого файлового агента к IWE описан в `AGENT-VENDOR-SETUP.md`, шаг 6. Этот документ — готовые промты под два конкретных инструмента, с проверенными шагами интерфейса.

## Что получится

- В ChatGPT или в Codex появится доступ к серверу знаний IWE (`iwe-knowledge`, `https://mcp.aisystant.com/mcp`) — поиск по Pack-репо, руководствам и цифровому двойнику.
- Подключение проходит через протокол единого входа (OAuth) под собственным аккаунтом Aisystant, без ручного ввода токенов.

## Аккаунт Aisystant (учётная запись МИМ)

Нужен для обоих сценариев ниже, оформляется бесплатно на [aisystant.system-school.ru](https://aisystant.system-school.ru/).

Отдельно регистрироваться заранее не обязательно — если аккаунта ещё нет, его можно завести по email прямо на экране OAuth-авторизации (шаг 6 промта ниже), это и есть шаг входа. Отдельный вход через Telegram-бота **@aist_me_bot** ([t.me/aist_me_bot](https://t.me/aist_me_bot)) — тот же аккаунт, просто ещё один канал, не обязателен для подключения MCP.

Войди под своим аккаунтом Aisystant в браузере по умолчанию на компьютере, где будешь подключать IWE, — до запуска промта из инструкции ниже. Иначе OAuth-авторизация откроется в чужой или пустой сессии, и придётся повторять попытку после входа.

Базовый доступ (поиск по базе знаний, инструменты вроде `agent_status_list`) бесплатный и не требует платной подписки. Платная подписка нужна только для более глубоких уровней платформы (персональное руководство, VS Code) — к подключению MCP из ChatGPT или Codex это не относится.

## Подключение к ChatGPT (личный или рабочий аккаунт)

### Где открывать чат

[chatgpt.com](https://chatgpt.com), под тем аккаунтом — личным или рабочим Work-пространством, — к которому нужно подключить IWE.

### Предварительные требования

- тариф ChatGPT Pro, Plus, Business, Enterprise или Education — на бесплатном плане кастомные MCP-подключения недоступны
- для рабочего (Business/Enterprise) пространства — при необходимости разрешение администратора (Workspace Settings → Permissions & Roles → Connected Data → «Create custom MCP connectors»); промт ниже сам остановится и попросит, если тумблер закрыт
- аккаунт Aisystant из раздела выше, вход в него в браузере по умолчанию
- агент с доступом к браузеру (Computer Use); если такого нет — все шаги промта можно пройти и вручную, ориентируясь на те же названия разделов интерфейса

### Промт для вставки в новый чат

```
Настрой MCP-сервер IWE в ChatGPT через интерфейс ChatGPT.

Параметры:
- Название (Name): IWE
- Описание (Description): доступ к базе знаний и цифровому двойнику IWE (Aisystant)
- URL: https://mcp.aisystant.com/mcp
- Аутентификация: OAuth

Используй подключённый Chrome через Computer Use. Если Chrome недоступен, используй встроенный браузер.

Порядок работы:
1. Открой Settings → Apps → Advanced settings.
2. Включи Developer mode. Если тумблер недоступен (рабочий аккаунт Business/Enterprise) — остановись и сообщи мне, что нужно разрешение администратора пространства (Workspace Settings → Permissions & Roles → Connected Data → «Create custom MCP connectors»).
3. Перейди в Settings → Connectors и нажми Create.
4. Проверь точное совпадение URL и заполни форму IWE (Name, Description, MCP server URL, Authentication: OAuth).
5. Перед окончательным созданием покажи заполненные параметры.
6. Если откроется экран OAuth-авторизации, логин, запрос пароля, MFA или подтверждение доступа — остановись и попроси меня выполнить этот шаг самостоятельно. Не запрашивай пароль в чате.
7. После авторизации открой Settings → Connectors → IWE и проверь список инструментов.
8. Если список пуст, нажми Refresh, подожди несколько секунд и проверь повторно.
9. Не считай настройку завершённой, пока среди инструментов не появится agent_status_list.
10. Открой новый чат, нажми «+» рядом с полем ввода, выбери IWE и убедись, что рядом с полем ввода появилась плашка IWE.

В конце сообщи отдельно:
- прошла ли OAuth-авторизация;
- появился ли agent_status_list;
- выбран ли IWE в новом чате.
```

### Проверка

Открой новый чат → нажми «+» → выбери IWE в списке инструментов. Рядом с полем ввода должна появиться плашка IWE — это надёжный признак, в отличие от цветных индикаторов в интерфейсе, которые меняются между версиями. Отправь тестовый запрос к базе знаний и убедись, что ChatGPT реально вызывает инструмент IWE, а не отвечает без него.

## Подключение к Codex

### Что такое Codex и где открывать чат

Codex — инструмент от OpenAI для работы с кодом из терминала (командной строки), устанавливается на свой компьютер отдельно от ChatGPT. «Чат Codex» — это не страница в браузере, а окно терминала с запущенной интерактивной сессией `codex`. Установка и официальная документация: [developers.openai.com/codex](https://developers.openai.com/codex/) (инструкции для Mac, Linux и Windows). После установки открой терминал, набери `codex` и работай в открывшейся сессии.

### Предварительные требования

- установленный и авторизованный Codex CLI (ссылка выше)
- аккаунт Aisystant из раздела выше, для входа при первом обращении к серверу

### Промт для вставки в чат Codex

```
Настрой локальный MCP-сервер IWE в Codex на этом компьютере.

Параметры:
- Имя сервера: iwe
- URL: https://mcp.aisystant.com/mcp
- Аутентификация: OAuth

Сначала проверь существующую конфигурацию командами `codex mcp list` и `codex mcp get iwe`. Не изменяй и не удаляй другие MCP-серверы.

Если IWE отсутствует, выполни:
`codex mcp add iwe --url https://mcp.aisystant.com/mcp`

Если требуется авторизация, выполни:
`codex mcp login iwe`

Когда откроется OAuth, логин, пароль, MFA или подтверждение доступа — остановись и попроси меня завершить этот шаг самостоятельно. Не запрашивай пароль в чате.

После авторизации проверь:
- `codex mcp get iwe` показывает правильный URL и `enabled: true`;
- `codex mcp list` показывает IWE со статусом `enabled` и OAuth;
- после перезапуска Codex или открытия новой задачи доступны инструменты `mcp__iwe__*`, включая `agent_status_list`.

Если сервер настроен, но инструментов в текущей задаче нет, не переустанавливай его повторно: сначала перезапусти Codex или открой новую задачу и проверь ещё раз.
```

### Проверка

`codex mcp get iwe` показывает `enabled: true`. После перезапуска Codex или новой задачи доступны инструменты `mcp__iwe__*`, включая `agent_status_list`.

## Troubleshooting

| Проблема | Решение |
|----------|---------|
| Раздел Developer mode / Connectors не открывается на рабочем аккаунте | Нужно разрешение администратора пространства — см. предварительные требования выше |
| Браузер для OAuth не открылся автоматически (headless/remote-сессия) | Скопируй ссылку авторизации из вывода агента и открой вручную на любом устройстве с браузером и доступом в интернет |
| Авторизация прошла, но не в том аккаунте Aisystant | Разлогинься в браузере по умолчанию из чужого аккаунта, повтори шаг авторизации |
| Список инструментов пуст после авторизации | ChatGPT: Settings → Connectors → IWE → Refresh. Codex: `codex mcp get iwe`, при необходимости перезапустить Codex |
