# Letter Template for External Developer / Candidate

> Used together with [`proposal-process.md`](proposal-process.md), section "External Developer / Candidate" — when the pilot confirms access to internal Packs for a specific approved idea. This template does not replace an NDA or legal agreement — no such policy exists yet.

---

Subject: Access to IWE materials for work on "[idea name]"

Hello, [Name]!

I am granting you read-only access to the following materials for work on the idea "[idea name]" (issue: [link]):

- [Pack 1] — [full access / sanitized excerpt]
- [Pack 2] — ...

**Access terms:**

- Access is valid until [date or "until work on the idea is complete"].
- These materials are intended for this work only — do not share them with third parties or use them for any other purpose.
- Revoking repository access closes access to future changes, but does not delete any copy you have already received — please delete your local copy after completing the work or if you decide not to continue.
- When the work is complete (or if you withdraw from the idea), let me know and I will revoke access.

Submit the result as a Pull Request to [repository] — use the acceptance criterion from your issue: [criterion].

Questions — write directly here.

[Pilot signature]

---

**How to use:** copy this template, fill in the placeholders (name, idea name, issue link, list of Packs, deadline, repository, acceptance criterion), and send it through the same communication channel already established with this person (see the identification condition in `proposal-process.md`).
