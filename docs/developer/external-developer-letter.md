# Шаблон письма внешнему разработчику/кандидату

> Используется вместе с [`proposal-process.md`](proposal-process.md), раздел «Внешний разработчик/кандидат» — когда пилот подтверждает доступ к внутренним Pack'ам под конкретную согласованную идею. Не заменяет NDA/юридическое соглашение — такой политики пока нет.

---

Тема: Доступ к материалам IWE для работы над «[название идеи]»

Здравствуй, [Имя]!

Даю тебе read-only доступ к следующим материалам для работы над идеей «[название идеи]» (issue: [ссылка]):

- [Pack 1] — [полный доступ / очищенная выдержка]
- [Pack 2] — ...

**Условия доступа:**

- Доступ действует до [дата или «до завершения работы над идеей»].
- Материалы предназначены только для этой работы — не передавай их третьим лицам и не используй в других целях.
- Отзыв доступа к репозиторию закрывает доступ к будущим изменениям, но не удаляет уже полученную тобой копию — пожалуйста, удали локальную копию после завершения работы или если решишь не продолжать.
- По завершении (или при отказе от идеи) — напиши мне, отзову доступ.

Результат присылай Pull Request'ом в [репозиторий] — критерий готовности из твоего issue: [критерий].

Вопросы — пиши прямо сюда.

[Подпись пилота]

---

**Как использовать:** скопировать, заполнить плейсхолдеры (имя, название идеи, ссылка на issue, список Pack'ов, срок, репозиторий, критерий готовности), отправить тем каналом связи, который уже использовался с этим человеком (см. условие идентификации в `proposal-process.md`).
