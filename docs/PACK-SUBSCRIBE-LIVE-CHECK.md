# Живая проверка подключения баз знаний других авторов

Подключение чужой базы знаний (навык `/pack-subscribe`) входит в выпуск 0.43 только после того, как его на своей установке проверит человек, который **не** автор шаблона. Если такой проверки нет к выпуску, навык переносится в 0.44.

Проверка занимает около десяти минут. Она скачивает одну открытую базу знаний (пак риторических приёмов) в вашу папку IWE и ничего в ней не меняет.

## Что нужно заранее

- Установка IWE версии 0.43 (кандидат выпуска) на macOS или Linux.
- VS Code с расширением Claude Code.
- Интернет: пак скачивается с GitHub.

## Шаг 1. Открыть папку IWE в VS Code

На macOS нажмите Cmd+Пробел, напишите `Visual Studio Code` и нажмите Enter. На Linux откройте VS Code из меню приложений.

Посмотрите на левую панель «Проводник»: вверху написано имя открытой папки. Если это не `IWE`, выберите в верхнем меню «Файл» → «Открыть папку…», найдите в домашней папке папку `IWE`, выделите её и нажмите «Открыть».

## Шаг 2. Начать беседу с агентом

Нажмите на значок Claude (оранжевая звёздочка) на боковой панели VS Code или вверху справа над открытым файлом. Откроется панель беседы. Если в ней уже идёт разговор, нажмите «New chat» (плюс вверху панели).

## Шаг 3. Посмотреть витрину

Напишите агенту в поле ввода внизу панели и нажмите Enter:

```text
какие паки есть
```

Агент покажет таблицу доступных баз знаний: четыре строки, среди них PACK-rhetoric (риторические приёмы). На этом шаге агент ничего не скачивает.

## Шаг 4. Подключить пак риторики

Напишите агенту в том же поле и нажмите Enter:

```text
подключи пак PACK-rhetoric
```

Если агент спросит разрешение запустить команду, нажмите «Yes» (разрешить). Через несколько секунд агент одной строкой сообщит, что пак подключён и сколько секунд это заняло. Запишите это число.

## Шаг 5. Открыть терминал

В верхнем меню VS Code выберите «Терминал» → «Новый терминал». Внизу окна откроется панель с мигающим курсором.

## Шаг 6. Убедиться, что пак лежит у вас

Вставьте эту команду в терминал и нажмите Enter:

```bash
ls "${IWE_WORKSPACE:-$HOME/IWE}/PACK-rhetoric"
```

Терминал покажет список файлов и папок пака, среди них `README.md`. Если вместо этого написано `No such file or directory`, подключение не удалось: остановитесь и сообщите об этом (раздел «Куда сообщить результат»).

## Шаг 7. Убедиться, что подписка записана в ваш файл

Вставьте эту команду в терминал и нажмите Enter:

```bash
grep -n "PACK-rhetoric" "${IWE_WORKSPACE:-$HOME/IWE}/extensions/protocol-open.after.pack-subscriptions.md"
```

Терминал покажет строку с именем `PACK-rhetoric` и датой подключения. Этот файл ваш: обновление шаблона его не трогает. Если терминал ничего не напечатал, подписка не записалась: отметьте это в отчёте.

## Шаг 8. Убедиться, что пак нельзя случайно изменить

Вставьте эту команду в терминал и нажмите Enter:

```bash
git -C "${IWE_WORKSPACE:-$HOME/IWE}/PACK-rhetoric" commit --allow-empty -m "проверка"; echo "exit=$?"
```

Терминал напечатает отказ: пак подключён только для чтения. Последняя строка должна быть `exit=` с числом, **не** равным нулю, например `exit=1`. Если последняя строка `exit=0`, защита не сработала: отметьте это в отчёте.

## Шаг 9. Найти ответ в подключённом паке

Вернитесь в панель беседы с агентом, напишите и нажмите Enter:

```text
найди в подключённых паках риторический приём, которым можно объяснить сложную идею через сравнение, и назови файл, откуда он взят
```

Агент должен ответить приёмом из пака риторики и назвать файл внутри папки `PACK-rhetoric`.

## Шаг 10 (по желанию). Отключить пак

Напишите агенту и нажмите Enter:

```text
отключи пак PACK-rhetoric
```

Агент попросит подтверждение. Ответьте «да», и он уберёт копию пака и строку подписки.

## Проверка пройдена, если выполнено всё сразу

1. На шаге 3 в витрине ровно четыре пака, среди них PACK-rhetoric.
2. На шаге 4 подключение заняло не больше минуты.
3. Шаги 6 и 7 показали пак и строку подписки.
4. На шаге 8 последняя строка не `exit=0`.
5. На шаге 9 агент назвал приём и файл из папки `PACK-rhetoric`.
